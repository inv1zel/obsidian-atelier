# OBSIDIAN — ателье детейлинга

> **Вымышленный проект для портфолио.** Ателье, команда, отзывы, цены и кейсы придуманы.
> Сайт не запрашивает и не хранит контактные данные: нет адреса, телефона и форм с именем или почтой.

Премиальный сайт ателье детейлинга в стилистике «тёмный люкс»: защита, цвет, свет.

## Возможности

- **Интро «Фары в темноте»**: ходовые огни зажигаются, фары вспыхивают, свет заливает экран. Звук запуска двигателя синтезируется Web Audio API, аудиофайлов нет. Интро показывается раз за сессию, его можно пропустить (кнопка или Esc).
- **Многостраничный сайт**: главная, услуги (5 направлений), работы, палитра плёнок, цены, ателье, запись, мои визиты.
- **Пошаговая запись**: класс авто → услуги с живым расчётом суммы и срока → дата и время → проверка → код брони вида `OBS-7K2F`.
- **Мои визиты**: перенос, отмена, экспорт в календарь (.ics). Всё хранится в `localStorage` браузера.
- **Слайдер «до / после»** с поддержкой мыши, касаний и клавиатуры.
- **Палитра плёнок**: примерка 12 оттенков в глянце, сатине и мате на SVG-силуэте.
- **Цены по классам автомобиля**: седан, кроссовер, внедорожник, суперкар.
- Адаптивная вёрстка, доступность (ARIA, фокус, `prefers-reduced-motion`).

## Стек

React 18 · Vite 5 · React Router (HashRouter) · чистый CSS без UI-библиотек.

## Запуск

```bash
npm install
npm run dev
```

Все фотографии лежат в `public/images`, их список и подписи — в `src/data/images.js`.

## Публикация

При пуше в `main` GitHub Actions собирает сайт и выкладывает его на GitHub Pages. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

## Безопасность

Сайт статический: нет сервера, базы данных, API и форм отправки. Атаковать на сервере нечего,
а от DDoS-атак сайт защищает инфраструктура GitHub Pages (CDN Fastly).

- **Content Security Policy** встраивается при сборке для публикации (`SECURE=1`, включено в GitHub Actions):
  скрипты, стили, шрифты и картинки загружаются только с самого сайта, плагины и отправка форм запрещены.
- **Referrer-Policy** `strict-origin-when-cross-origin`.
- **Нет сторонних запросов:** шрифты лежат в проекте, аналитики и трекеров нет.
- **Нет опасных конструкций:** `dangerouslySetInnerHTML`, `eval` и внешних ссылок нет, React экранирует весь вывод.
- **Данные из `localStorage` проверяются:** испорченные или подменённые записи отбрасываются, длина полей ограничена, хранится не больше 50 записей.
- **Параметры ссылок очищаются:** `?note=` обрезается до 120 символов, управляющие символы и `<>` удаляются.
- **Страховка от падений:** ошибка в одном блоке показывает аккуратную заглушку, а не белый экран.
- **Зависимости:** при каждой публикации `npm audit` прерывает сборку при уязвимостях высокого уровня; Dependabot еженедельно предлагает обновления.

## Права и лицензии

### Фотографии

Фотографии подобраны из открытых источников и обработаны под стилистику сайта.
Права на них принадлежат авторам, поэтому сайт допустимо показывать только как
некоммерческий концепт в портфолио. Перед любым коммерческим использованием —
продажей шаблона, сдачей клиенту, рекламой — все фото нужно заменить на собственные,
сгенерированные в сервисе с коммерческой лицензией или купленные на стоке.
Пути и подписи всех фото собраны в `src/data/images.js`.
